# TODO Scratchpad — PyTA

## Sprint 11.5: the major technical indicators ☐ (planned 2026-10-29)

Plan of record: `docs/DEVELOPMENT.md`, "Sprint 11.5 — The major technical indicators". Goal: ship the 24 technical indicators in the README catalog beyond SMA, EMA, MACD, RSI and CCI, so PyTA can replace TA-Lib for everyday technical analysis.

**Formula rule for this sprint (2026-10-29, user):** follow a professional standard where one exists; where none does, follow TA-Lib. Research (four researchers, 2026-10-29, key claims checked against TA-Lib's C source) found **no formal standard (ISO, exchange, regulator) for any of the 24**: each has an original author's definition (Wilder, Lane, Bollinger, Chaikin, ...) and TA-Lib, the de facto implementation, follows those originals in its formulas. They differ only in defaults, seeding and zero-denominator conventions, listed per indicator in Part A. So TA-Lib's calculation is the rule; the five indicators TA-Lib lacks follow the definition the major references (StockCharts, TradingView) share.

Where things stand:
- **TA-Lib changes under us.** C library v0.8.3 (2026-10-25) rewrote the flat-window guards in STOCH, MFI, ULTOSC and WILLR (scaled zero tests, fixes #107/#130/#253), moved BBANDS' default period from 5 to 20, and replaced the naive sum-of-squares variance. Older releases (0.4.x/0.6.x) give different values on flat or large-offset data. Fixtures must name one release.
- **Engine:** `Params` derives `Eq` (`pyta-engine/src/requests.rs:27`), which an `f64` field cannot satisfy; float parameters mean dropping `Eq` (keep `PartialEq`). A variant with no fields (`Params::Obv`) already works with the exhaustive matches.
- **Python:** `_validation.py` has integer validators only (`validate_period`, `validate_fast`, ...); the `volume` role is registered (`_validation.py:105`); high-below-low is checked in `_columns.py` (`ORDERED_ROLES`).
- **Shared code today:** none of true range, Wilder smoothing, rolling highest/lowest, typical price or rolling standard deviation exists as a reusable helper; CCI computes its own typical price and has a private `ZERO_TOLERANCE` (1e-14) in `pyta-momentum/src/cci.rs`.
- **Crates:** `pyta-trend`, `pyta-momentum` exist; `pyta-volatility`, `pyta-volume` do not. Category crates may not depend on each other, so TRIX (momentum) and Keltner (volatility) cannot call `pyta-trend`'s EMA: shared kernels go in `pyta-core` (see B1).
